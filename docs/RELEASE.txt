HOW TO RELEASE DEALERDESK
=========================

Only release a commit whose CI job has passed (Actions tab on GitHub).

1. Build on your machine (see README)
2. Test it a bit: add a car, do a quote, sell a car, check the invoice looks right.
   PUT THE DATA FILES BACK AFTERWARDS!!
3. On \\fileserver01\apps\dealerdesk\ rename dealerdesk to dealerdesk.old
4. Copy the new dealerdesk binary there
5. Email the showrooms that a new version is out
6. If something breaks, copy dealerdesk.old back

Last release: 2.3 (2021-04-08)  - P.
